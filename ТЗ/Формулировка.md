**Постановка задачи:**

На основе информации из источников MalwareBazaar (https://bazaar.abuse.ch/), APT ETDA (https://apt.etda.or.th/cgi-bin/aptgroups.cgi) и Virus Total (https://www.virustotal.com) сформировать фид со следующей структурой:
```
{
	"md5": "...",
	"sha256": "...",
	"malware_class": ["...", ],
	"malware_family": ["...", ],
	"av_detects": ["...", ],
	"threat_level": "..."	
}
```

**Детализация:**

1. Основой для выгрузки должны являться хэши последних 100 образцов вредоносного ПО, загруженного на MalwareBazaar.
2. Поле malware_class заполнять на основе совмещения данных из поля signature (MalwareBazaar) и данных из APT ETDA.
3. Поле av_detects заполнять на основе данных из VirusTotal.
4. Поле threat_level заполнять на основе аналитики над полем malware_class. Логику аналитики вам требуется определить самостоятельно. Минимальный набор значений, которое принимает поле threat_level: LOW, MEDIUM, HIGH.
5. Вывод осуществлять в формате JSONL.

**Ожидаемое решение:**

1. Код программы сформирован, корректно функционирует и состоит из следующих логических частей:
	- Модуль импорта. Осуществляет сбор и парсинг информации из вышеописанных источников.
	- Модуль совмещения данных. Осуществляет сравнение данных, полученных из разных источников и формирует маппинги.
	- Модуль аналитики. Осуществляет анализ контекста индикатора и заполняет поле threat_level.
	- Модуль экспорта. Осуществляет формирование фида в формате JSONL.
2. Фид сформирован. Его структура соответствует заявленной в задании.
3. Описана и обоснована логика заполнения поля threat_level. Логика корректно реализована в коде.
